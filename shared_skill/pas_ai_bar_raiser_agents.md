# PAS AI Bar Raiser Agents

Two AI-powered agents to accelerate COE writing/review and API schema quality across PAS.

## PAS COE Bar Raiser Agent

Assists COE authors and reviewers with automated feedback on language, format, completeness, data references, learnings, and action items — ensuring every COE meets the bar before human review cycles begin.

**Access:**
- Quick Chat Agent: `PAS COE Bar-Raiser Agent`
- Install via CLI: `aim agents install SupplyTechAICapabilities`
- Review with Claude: `claude pubtech-coe-bar-raiser`
- Source code: https://code.amazon.com/packages/SupplyTechAICapabilities/trees/mainline/--/agents

**Impact:**
- ~90% reduction in COE authoring time (from 25-30 hours → ~3 hours)
- ~67% reduction in review cycle time (from 2-3 hours → < 1 hour)

## PAS API Schema Bar Raiser Agent

Reviews PAS API schema changes for consistency, convention adherence, and completeness — catching common issues early in the development cycle.

**Access:**
- Quick Chat Agent: `PAS API Schema Bar Raiser`
- Install via CLI: `aim agents install SupplyTechAICapabilities`
- Review with Claude: `claude pas-api-schema-bar-raiser`
- Source code: https://code.amazon.com/packages/SupplyTechAICapabilities/trees/mainline/--/agents
